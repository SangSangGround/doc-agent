# iPhone 질문 화면 대화 UX 개선

`feat/ios-document-consent` 브랜치의 iPhone 앱에서 **문서에 질문하기** 화면의 주고받는 흐름을 다듬었다. 화면 쪽(`ios/DocAgentApp`)만 바꿨고 엔진(`ios/DocAgentCore`)은 수정하지 않았다. 답을 찾는 방식, 답 문구, 원문 그대로 읽는 원칙은 그대로다.

## 추가한 기능

| 기능 | 목적 | 실기기 확인 |
|---|---|---|
| 대화 이어가기 | 질문할 때마다 버튼을 찾지 않고 말로 계속 묻는다 | 확인함 |
| 기다림 신호 | 답을 찾는 동안 앱이 멈춘 것이 아님을 소리와 진동으로 알린다 | 미확인 |

### 1. 대화 이어가기

**말로 질문하기**를 처음 한 번 누르고 질문하면, 답을 끝까지 읽은 뒤 짧은 소리(시스템 사운드 1113)와 진동을 주고 마이크를 다시 켠다. 사용자는 버튼 없이 바로 다음 질문을 말한다.

```
말로 질문하기(1회) → 질문 → 답 읽기 → 띵+진동 → 마이크 자동 시작 → 다음 질문 → …
```

- 화면에 **답을 듣고 바로 이어서 말하기** 스위치를 추가했다. 기본값은 켜짐이며, 끄면 이전처럼 질문마다 버튼을 누른다.
- 마이크는 답 읽기가 **끝까지 끝난 뒤에만** 켠다. 소리 뒤 0.45초를 기다려 앱 소리가 질문으로 인식되지 않게 했다.
- 대화가 끝나는 경우
  - "그만", "끝", "종료", "고마워"가 들어간 8글자 이하의 말, 또는 "됐어"만 말했을 때 → "대화를 마칠게요."
  - 대화 중 8초 동안 말이 없을 때 → "대화를 마칠게요. 다시 질문하려면 말로 질문하기를 눌러 주세요."
  - **읽기 멈추기**, **질문 취소**, **녹음 취소**를 누르거나, 글로 질문하거나, 화면을 닫거나 앱이 백그라운드로 갈 때
- "어떻게 됐어?"처럼 질문 안에 "됐어"가 있는 경우는 종료하지 않는다.
- 첫 질문은 이전과 같이 12초를 기다리고, 말이 없으면 "질문을 듣지 못했어요" 안내를 한다.

### 2. 기다림 신호

답을 찾는 동안(`HomeModel.pendingQuestion`이 있는 동안) 다음 순서로 알린다.

| 질문 후 경과 | 동작 |
|---|---|
| 0.6초 안에 답이 나옴 | 신호 없음 |
| 0.6초 | "찾아보고 있어요." (홈 화면 **음성 안내** 설정을 따름) |
| 2초부터 | 1.5초마다 틱 소리(시스템 사운드 1104)와 약한 진동 |
| 답이 나오거나 취소됨 | 즉시 멈춤 |

틱 소리는 iPhone 키보드 클릭 소리를 사용하므로 무음 모드이거나 **설정 → 사운드 및 햅틱 → 키보드 피드백 → 사운드**가 꺼져 있으면 진동만 난다. 음성을 읽는 중에는 틱 소리를 내지 않는다.

## 바뀐 파일

| 파일 | 변경 |
|---|---|
| `ios/DocAgentApp/HomeModel.swift` | 질문 답변을 중간에 멈추지 않고 끝까지 읽었을 때 `answerSpokenCount`를 1 올린다. `AVSpeechSynthesizerDelegate`를 받는 `SpeechEvents`를 추가했다. `speak()`가 만든 `AVSpeechUtterance`를 돌려준다. `continuousConversation` 설정을 추가했다. |
| `ios/DocAgentApp/QuestionMicrophone.swift` | `begin(waitSeconds:onSilence:onQuestion:)`로 기다릴 시간과 말이 없을 때의 처리를 지정할 수 있다. 기존 호출 방식은 그대로 동작한다. |
| `ios/DocAgentApp/ConsentQuestionView.swift` | 대화 이어가기 스위치와 안내 문구, 종료 단어 판정(`isStopCommand`), 마이크 다시 켜기, 기다림 신호를 추가했다. |

엔진의 공개 함수(`DocumentReviewer.answer`, `ConsentReply`, `ConsentTurn`)는 이전과 같은 방식으로만 사용한다.

## 확인 방법

1. 동의서를 촬영하거나 사진으로 불러온 뒤 **문서에 질문하기 → 말로 질문하기**를 누른다.
2. "내 정보는 누구에게 제공돼?"라고 묻는다. 답이 끝나면 띵 소리와 진동 뒤 마이크가 켜지는지 확인한다.
3. 버튼 없이 "동의 안 하면 어떻게 돼?"라고 묻는다.
4. "대출 개인정보가 잘못 쓰인 실제 사례가 있어?"처럼 답이 몇 초 걸리는 질문에서 "찾아보고 있어요"와 틱 소리가 나는지 확인한다.
5. "그만"이라고 말하거나 8초 동안 말하지 않아 대화가 끝나는지 확인한다.

`xcodebuild -project ios/DocAgent.xcodeproj -scheme DocAgent -destination 'generic/platform=iOS' CODE_SIGNING_ALLOWED=NO build`로 컴파일을 확인했다. 자동 테스트는 추가하지 않았다.

## 남은 일

- 답을 읽는 도중에 끊고 바로 질문하는 기능은 없다. 지금은 **읽기 멈추기**를 누르거나 답이 끝나기를 기다린다.
- 종료 단어는 고정 목록이다. 사용자 시험에서 자주 쓰는 표현이 나오면 추가한다.
- 답을 찾지 못했을 때("촬영한 이 면에서 질문에 답할 문구를 확인하기 어려워요") 물어볼 수 있는 항목을 안내하는 기능은 아직 없다.
