# 집에서 문서 읽기와 체크 결과 확인

하드웨어와 Jev 없이, 촬영 안내 → 지원 양식 확인 → 검토된 원문 읽기 → 사용자 선택 재확인 → 작성 후 체크 대조를 실행하는 로컬 MVP다. 실제 지원 문서는 **동의서 1종으로 정하되 양식은 아직 미선정**이다. 제공하는 데모는 테스트용 가상 동의서이며 실제 동의·신청에 사용할 수 없다.

## 실행

저장소 루트에서 기존 `venv`를 사용한다. 새 가상환경이나 외부 AI 계정은 필요하지 않다.

```bash
source venv/bin/activate
export PYTHONPATH=src
python -m docagent.home demo --output outputs/home-demo
python -m docagent.home serve --template outputs/home-demo/template.json --demo --session outputs/home-demo/session.json
```

`demo` 출력 폴더는 비어 있어야 한다. 이미 생성했다면 `serve`부터 실행한다. `http://127.0.0.1:8765`에 접속한다. `--port`로 포트를 바꿀 수 있다. `--session`을 생략하면 선택 상태를 파일로 저장하지 않는다. 서버는 이 컴퓨터의 루프백에서만 접속되므로 휴대전화에서 이 주소를 입력해서 접속하는 구조는 아니다.

PowerShell은 기존 가상환경을 활성화한 뒤 `$env:PYTHONPATH = 'src'`를 설정한다. 프로젝트를 `python -m pip install -e '.[dev,ocr]'`로 설치했다면 `PYTHONPATH` 설정은 생략할 수 있다. 실제 마스킹 후보 탐지에는 로컬 Tesseract와 `kor+eng` 언어 데이터, `pytesseract`가 필요하다.

## 화면에서 확인할 흐름

1. `reference.png`를 불러온다. 생성된 이미지는 페이지 전체를 담은 스캔이므로 **스캔 이미지**를 선택한다. 실제 사진에서는 이 설정을 해제한다.
2. 현재 항목이나 전체 원문을 읽는다. 음성은 설치된 한국어 로컬 음성만 사용하며, 없으면 화면 읽기 기능과 텍스트를 사용한다.
3. 항목마다 ‘동의하지 않음’을 고르고 **선택 내용 재확인 → 이 선택으로 확정**을 누른다.
4. `correct.png`, `opposite.png`, `missing.png`, `duplicate.png`, `blurred.png`를 각각 불러오고 **촬영한 체크 결과 대조**를 누른다.
5. 순서대로 정상 일치, 반대 선택지, 미표시, 중복 표시, 판독 불가를 확인한다.

카메라를 사용하면 연속 프레임의 문서 경계·흐림·밝기·기울기·움직임을 검사하고 재촬영 안내를 제공한다. 안정된 프레임이 이어질 때 촬영 준비 상태로 바뀐다. 모델을 호출해 매 프레임 설명을 생성하지 않으며 같은 경고를 짧은 간격으로 반복하지 않는다. 음성 명령 인식은 이번 실행 경로에 포함하지 않았고 버튼·키보드·스크린리더로 조작한다.

## 구현 내용

| 기능 | 동작 |
|---|---|
| 촬영 안내 | 기존 OpenCV 품질 검사와 연속 프레임 안정성·안내 반복 억제 |
| 양식 확인과 정렬 | 검토된 빈 기준 이미지에 특징점·인쇄 내용·페이지 영역을 대조해 정렬 |
| 원문 안내 | 등록된 페이지·항목 원문을 공백과 줄바꿈까지 보존해 제공 |
| 선택 상태 | 항목 ID와 선택지 ID로 제안·확정·취소·이전/다음 이동 |
| 체크 판독 | 칸별 marked / unmarked / uncertain, 그룹별 미표시·단일·복수·불확실 |
| 결과 대조 | 확정한 선택과 실제 표시의 일치·불일치·누락·허용 개수 초과 안내 |
| 로컬 저장 | 문서 묶음 지문, 항목 위치, 선택 ID, 읽기 속도만 저장. 재실행 후 이미지 판정은 초기화 |
| 마스킹 초안 | 로컬 OCR 단어 좌표와 기존 개인정보 규칙으로 가림 후보 및 미리보기 생성 |
| 평가 | 오완료율·문제 발견율·정상 완료율·판독 불가율과 각 분모/분자 출력 |

새 촬영, 선택 변경, 유효하지 않은 검증 결과가 들어오면 이전 완료 판정을 폐기한다. 선택을 제안·확정·취소한 뒤에는 새로 촬영해야 다시 대조할 수 있다. 판독 불가를 미체크로 취급하지 않는다. 문서 정합은 확인되고 체크 표시만 불확실한 경우에는 원문 읽기를 허용하되 완료 판정은 보류한다. 복수 선택 허용 여부는 각 항목의 `min_selected`, `max_selected`로 설정한다. 하나만 선택하는 항목에 두 개를 표시하면 중복 안내를 한다.

기존 RF-DETR 추론·OCR·검수 도구는 양식의 체크박스 좌표를 준비하는 데 사용할 수 있다. 새 홈 실행 경로는 **검토해 등록한 좌표**를 이용하며 매번 Roboflow를 호출하지 않는다. 객체 탐지 학습을 다시 진행하거나 체크 여부 분류 모델을 학습한 작업은 아니다.

## 개인정보 처리

홈 실행 경로에는 외부 AI·Roboflow·클라우드 STT/TTS 호출이 없다. 서버는 127.0.0.1에만 바인딩하며 요청의 Host·Origin과 세션 토큰을 검사한다. 원본 이미지와 OCR 원문을 앱 저장 파일이나 세션 파일에 쓰지 않는다. **pytesseract는 실행 중 OS 임시 파일을 사용할 수 있으므로 ‘완전 메모리 전용’이라고 표현하지 않는다.**

자동 마스킹은 승인 기능이 아니다. OCR 오류, 이름·주소 등 규칙에 없는 정보가 남을 수 있다. 후보가 0개여도 개인정보가 없다고 판단하지 않는다. 모든 결과에 외부 전송 불허와 검토 필요 상태를 유지한다. 기존 Roboflow 경로에 사용하려면 별도 이미지별 마스킹 검토·승인이 필요하다.

세션 선택 ID도 문서와 결합하면 사용자 의사를 드러낼 수 있다. `--session`은 로컬 이어하기가 필요한 경우에만 설정한다. 양식 파일의 원문에는 개인별 입력값을 등록하지 않고 공통 인쇄 원문을 사용한다.

## 실제 동의서 등록

양식을 정한 후, 빈 페이지 기준 이미지와 검토할 전체 원문, 체크박스 묶음 JSON을 준비한다. 현재는 A4 단일 페이지를 기본으로 한다. `box_mm`는 페이지 왼쪽 위 기준 `[x, y, 너비, 높이]`다. 항목 원문은 페이지 전체 원문에 그대로 포함된 구간이어야 한다.

```json
[
  {
    "id": "consent_1",
    "source_text": "전체 원문에서 그대로 복사한 해당 항목",
    "min_selected": 1,
    "max_selected": 1,
    "options": [
      {"id": "agree", "label": "동의함", "box_mm": [25, 110, 6, 6]},
      {"id": "disagree", "label": "동의하지 않음", "box_mm": [100, 110, 6, 6]}
    ]
  }
]
```

위 좌표는 형식 예시다. 실제 양식에 그대로 적용하면 안 된다.

```bash
python -m docagent.home draft-template \
  --reference blank.png --text original.txt --groups groups.json \
  --document-id consent-example --version 1 --title '선정한 동의서' \
  --source '공식 원문 출처' --output outputs/consent-bundle
```

이 명령은 `production`의 `draft` 묶음을 만든다. 검토자가 전체 원문, 항목 문구, 선택 규칙, 좌표, 빈 기준 이미지와 출처를 확인한 뒤에만 다음 명령을 실행한다.

```bash
python -m docagent.home approve-template \
  --template outputs/consent-bundle/template.json \
  --reviewer '실제 검토자 이름' --confirm-reviewed
python -m docagent.home serve --template outputs/consent-bundle/template.json
```

승인 기록과 이미지 SHA-256은 내용 변경을 감지한다. 검토자 신원이나 법적 효력을 인증하는 기능은 아니다. 원문·이미지·좌표가 바뀌면 다시 검토한다. 이번 작업에서는 실제 동의서를 임의로 승인하지 않았다.

## 평가와 해석

```bash
python -m docagent.home evaluate \
  --manifest outputs/home-demo/evaluation.json --demo \
  --output outputs/home-demo/results.json
python -m pytest -q
node tests/home/browser_state_check.cjs
```

Node 명령은 추가 npm 패키지 없이 실행하는 비동기 화면 상태 회귀 테스트다. 실제 브라우저·카메라 테스트를 대신하지 않는다. Python 테스트와 합성 데모 생성·평가는 기존 GitHub Actions에도 연결했다.

합성 기본 사례 5건은 정상 1건, 반대 칸·미표시·중복 표시 3건, 흐린 이미지 1건이다. 데이터셋의 성격과 분모를 결과 JSON에 남긴다.

- **오완료율**: 실제 완료가 아닌 사례 중 완료라고 판정한 수 / 완료가 아닌 사례 수. 흐림·판독 불가 정답도 분모에 포함한다.
- **문제 발견율**: 실제 오표시·누락·중복 사례 중 문제를 발견한 수 / 문제 사례 수. 단순 판독 불가를 문제 발견 성공으로 세지 않는다.
- **정상 완료율**: 정상 사례 중 완료라고 판정한 수 / 정상 사례 수.
- **판독 불가율**: 불확실 판정 사례 수 / 전체 사례 수. 전부 거절해 오완료율만 낮추는 문제를 확인한다.

분모가 0인 지표는 `null`이다. 실제 데이터는 `dataset_kind: real`, 정답 검토자 `reviewed_by`, 데이터셋 버전 `dataset_version`을 명시한다. 튜닝에 사용한 문서와 최종 평가 문서를 분리하고, 동의서 종류뿐 아니라 촬영 조건·표시 방식도 다양하게 확보해야 한다.

### 이번 구현 검증 (2026-11-04)

- 전체 Python 회귀 테스트: **1,817개 통과**. 기존 기능 테스트를 포함한다.
- 비동기 화면 상태 회귀: **7개 통과**. 중복 조작, 초기화 실패, 늦게 반환된 카메라·서버 응답을 검사했다.
- 합성 5건 평가: 오완료 **0/4**, 문제 발견 **3/3**, 정상 완료 **1/1**, 판독 불가 **1/5**. 개발 중 만든 사례이므로 일반화 성능으로 제시하면 안 된다.
- 실제 브라우저: 빈 합성 문서 불러오기 → 두 항목 선택·확정 → 작성된 합성 사진 불러오기 → 일치 결과 표시 → 로컬 마스킹 후보 미리보기를 확인했다.
- 로컬 Tesseract: 합성 전화번호·주민번호의 가림 후보를 확인했다. 실제 개인정보 마스킹 재현율은 아직 측정하지 않았다.

## 남은 실제 검증

실제 동의서 선정·원문/좌표 검토, 사진별 마스킹 정답, 체크 상태 정답셋, 실제 카메라와 스크린리더·시각장애인 사용자 검증이 필요하다. 합성 회귀 테스트는 외부 문서 정확도나 독립 작성 성공률을 증명하지 않는다. 이 MVP는 작성 위치로 손을 유도하지 않으며 서명 진위·법적 유효성을 판정하지 않는다.
