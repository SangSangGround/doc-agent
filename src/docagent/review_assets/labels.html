정답 박스 검수

모든 박스는 미승인 초안입니다. 페이지 전체를 보면서 빠진 항목을 추가하고 잘못된 항목을 삭제하세요. 서명 위치는 인쇄된 ‘서명’ 글자와 실제 서명 공간을 구분해 팀의 라벨 기준으로 확인하세요. 저장만으로 정답 승인이나 정확도 측정이 완료되지 않습니다.

박스 확인

박스를 클릭한 뒤 좌표·크기·클래스를 수정할 수 있습니다. 좌표 단위는 원본 이미지 픽셀입니다.

    검수 결과 저장

    모든 체크박스와 서명란의 누락·클래스·경계를 확인한 후 초안을 저장하세요. 대상이 전혀 없는 페이지는 박스 0개로 저장할 수 있습니다.

    내보낸 JSON에는 COCO가 coco 키 안에 들어 있습니다. 사람이 검수한 뒤 python -m docagent.label_review approve 명령으로 승인해야 평가용 COCO가 생성됩니다.

    이 화면은 외부 서버에 접속하지 않습니다. 원본 파일은 수정하지 않으며 브라우저를 닫으면 저장하지 않은 변경은 사라집니다.
