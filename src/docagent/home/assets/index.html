검토된 원문을 그대로 읽습니다. 선택 결과는 확인 버튼을 누른 뒤 저장됩니다.

3. 체크 결과 확인
선택한 항목에 표시한 뒤 위에서 다시 촬영하거나 작성한 사진을 불러오세요. 작성 위치로 손을 유도하는 기능은 제공하지 않습니다.


개인정보 가림 후보
이 화면의 문서 사진은 이 컴퓨터에서 처리합니다. 이름·주소 등 일부 정보는 자동 탐지에서 빠질 수 있어, 후보가 모든 개인정보를 가렸다는 뜻은 아닙니다.


원본 이미지를 앱의 저장 파일에 보관하지 않습니다. 로컬 OCR 실행 중 임시 파일이 사용될 수 있습니다. 세션 저장을 설정한 경우 선택 ID와 진행 상태만 로컬 파일에 저장됩니다. 음성 입력 대신 버튼과 키보드로 조작하며, 기기에 설치된 음성 또는 화면 읽기 기능을 사용합니다.
